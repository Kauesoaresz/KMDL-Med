# RESUMO COMPLETO DO SISTEMA KMDL-Med (KMed)

## 1. VISÃO GERAL
- **Nome do Projeto**: KMDL-Med (provavelmente "KMed" - sistema para estudos médicos)
- **Tecnologias**:
  - Backend: Node.js (Express.js) com Sequelize ORM (models/index.js)
  - Frontend: EJS templates, CSS customizado, JavaScript vanilla
  - Banco de Dados: MySQL/PostgreSQL (scripts SQL em db/)
  - Uploads: Multer (config/upload.js)
  - Autenticação: Middleware custom (middlewares/auth.js)
- **Propósito**: Plataforma de estudos para medicina com:
  - Cadastro de estudos diários
  - Metas de estudo
  - Provas e simulados (com blocos, erros, estatísticas)
  - Revisões espaçadas
  - Dashboard, relatórios, perfil
  - Conteúdo hierárquico: Matérias → Assuntos → Tópicos → Subtópicos
- **Estrutura**: MVC completo (Models, Views, Controllers, Routes)
- **Dependências**: Gerenciadas por npm (package.json/package-lock.json)
